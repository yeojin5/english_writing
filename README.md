# English Writing Practice ✍️

매일 다섯 문장씩 한→영 작문 연습을 하는 저장소입니다.

## 진행 방식
1. 그날의 한글 예문 5개를 준비합니다 (특정 문법·동사+전치사 조합 등을 반복 연습하도록 구성).
2. 첫 번째 문장을 영작해서 답하면 → **교정 + 틀린 부분 설명** → 다음 예문 제시, 순서로 진행합니다.
3. 5문장이 끝나면 예문 / 내가 쓴 문장 / 교정 문장 / 틀린 표현 / 학습할 부분을 `daily/YYYY-MM-DD.md`에 정리해 커밋·푸시합니다.
4. 틀린 표현과 맞춘 표현 모두 `review/tracker.md`에 기록하고, 며칠 간격(간격 반복: 2일 → 4일 → 7일 → 14일)으로 응용 문제로 다시 출제합니다.
   - 틀리면 간격을 처음(2일)으로 되돌리고, 맞히면 다음 간격으로 늘립니다.

## 구조
- `daily/` — 날짜별 연습 기록
- `review/tracker.md` — 복습 항목과 다음 복습 예정일

## 브랜치 규칙
- **모든 기록은 `main` 브랜치에 계속 커밋·푸시합니다.** (2026-11-09부터)
- 매일 시작할 때 `main`을 먼저 pull 해서 이전 기록과 `review/tracker.md`를 이어서 사용합니다.
- 예전 `claude/*` 브랜치들은 Day 1~4 작업 이력이며, 내용은 모두 `main`에 들어 있습니다.
