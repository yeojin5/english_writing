## 기록 (답변 후 채움)

### 1.
- 예문: 요즘 나는 이 프로젝트에서 모델 평가를 맡고 있어.
- 내가 쓴 문장: These days, I work on evaluate to model of this project.
- 교정한 문장: These days, I'm responsible for model evaluation in this project. (= These days, I'm in charge of evaluating the model on this project.)
- 틀린 표현:
  - `work on` → `be responsible for` / `be in charge of` ("맡고 있다" = 역할·책임. work on은 "~ 작업을 하고 있다"라서 맡은 역할이라는 뜻이 약함. 쓰려면 these days와 함께 진행형 I'm working on model evaluation)
  - `evaluate to model` → `model evaluation` / `evaluating the model` (전치사 뒤에는 동사원형 ❌ → 명사나 -ing. to도 불필요. model은 셀 수 있는 명사라 단독 ❌ → the model)
  - `of this project` → `in / on this project` (Day 1과 같은 실수 ⚠️ "프로젝트에서" ≠ of)
- 학습할 부분:
  - ✅ These days (Day 1의 These day를 바로잡음)
  - 전치사(for/of/on/about) + 동사 → 반드시 -ing 또는 명사: responsible for evaluating / in charge of evaluation
  - 작업명은 명사+명사로 쓰고 관사 없이: model evaluation, data preprocessing, hyperparameter tuning
  - "~에서 맡은 일" → in/on a project (2회째 반복 → 다음 복습도 2일 뒤)
