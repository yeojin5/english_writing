## 기록 (답변 후 채움)

### 1.
- 예문: 나는 3주째 이 버그를 고치고 있어.
- 내가 쓴 문장: I am fixing this bug for 3 weeks.
- 교정한 문장: I've been trying to fix this bug for three weeks. (= I've been working on this bug for three weeks.)
- 틀린 표현:
  - `I am fixing ... for 3 weeks` → `I've been fixing / I've been trying to fix ...` (과거부터 지금까지 계속 → 현재진행 ❌, 현재완료진행 have been -ing ✅)
  - (자연스러움) `fixing` → `trying to fix` / `working on` (아직 못 고쳤으니 '고치려고 애쓰는 중')
  - (스타일) `3 weeks` → `three weeks` (글에서는 보통 1~9를 철자로)
- 학습할 부분:
  - ✅ 기간 전치사 for + 기간 정확히 사용
  - ✅ this bug (관사/지시어) 정확
  - for + 기간이 붙어 "지금까지 계속"을 말하면 현재진행이 아니라 have been -ing
  - 한국어 "~째 ~하고 있어" = I've been -ing for ~
  - work on + 작업 대상 (work on a bug / a paper / a project)
